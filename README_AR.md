# Himaya Security 0.7.0

Himaya Security تطبيق Windows لإدارة قيود محلية على المواقع والتطبيقات والمجلدات، من خلال واجهة عربية وخدمة تعمل في الخلفية.

> **حالة المشروع:** إصدار تطويري قبل الإطلاق العام. المزايا والتوافق ما زالا قيد الاختبار. لا تعتمد على Himaya باعتباره وسيلة الحماية الوحيدة أو بديلًا لمضاد الفيروسات.

## الوظائف الحالية

- واجهة عربية لإدارة قوائم المواقع والتطبيقات والمجلدات.
- حفظ الإعدادات وسجل الأحداث محليًا باستخدام SQLite.
- حظر النطاقات التي يضيفها المستخدم من خلال ملف Windows hosts.
- إمكانية استيراد قائمة نطاقات مجتمعية من مصدر خارجي.
- تقييد تشغيل تطبيقات مختارة باستخدام آليات سياسات Windows.
- تقييد الوصول إلى مجلدات مختارة باستخدام أذونات Windows ACL، مع الاحتفاظ ببيانات الاستعادة.
- خدمة Windows باسم `HimayaGuard`.
- تصدير أحدث الأحداث إلى ملف CSV.

## حدود مهمة

- حظر المواقع من خلال hosts يمكن تجاوزه باستخدام VPN أو Proxy أو DNS مشفر أو إعدادات DNS خاصة بالمتصفح.
- تعتمد قيود التطبيقات والمجلدات على سياسات Windows وصلاحياته. يستطيع المسؤول المحلي تغيير إعدادات النظام أو إيقاف الخدمة أو إزالة التطبيق.
- بعض اختيارات الملفات الشخصية تحفظ الاختيار في الإعدادات، لكنها لا تطبق حتى الآن جداول أو سياسات حماية مختلفة بالكامل. لا تعتبر اسم الوضع ضمانًا لمستوى حماية مستقل.
- قائمة النطاقات المجتمعية يديرها طرف ثالث وقد تتغير أو يتعذر الوصول إليها.
- قد يختلف السلوك حسب إصدار Windows وإعدادات الجهاز.
- Himaya ليس برنامج مكافحة فيروسات ولا يوفر حماية مطلقة.

## متطلبات البناء

- Windows 11 x64 (الهدف الحالي).
- Visual Studio 2022 مع Desktop development with C++.
- CMake 3.24 أو أحدث.
- Inno Setup 6 لبناء ملف التثبيت.
- اتصال بالإنترنت عند إعداد بناء جديد لتنزيل SQLite عند الحاجة.

من مجلد المشروع شغّل:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --parallel
```

لبناء المثبت بعد نجاح البناء:

```powershell
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" "Installer\Himaya.iss"
```

## الاختبارات والإصدارات

يتضمن المستودع GitHub Actions workflow لبناء التطبيق والخدمة، وتشغيل اختبارات تحقق لسياسات Windows والخدمة، وتجهيز المثبت. يجب أن ينجح تشغيل Workflow قبل نشر أي إصدار. الاختبارات الآلية لا تغني عن التجربة على جهاز Windows 11 نظيف.

لا يوجد إعلان عن إصدار تثبيت عام من هذا الفرع حتى الآن.

## الخصوصية

يحفظ التطبيق الإعدادات وسجل الأحداث محليًا ضمن مجلد ProgramData في Windows. راجع الكود وأي إشعار خصوصية يصدر مع النسخة قبل الاستخدام. لا يدعي المشروع أن هذه البيانات تُرسل إلى خادم تابع لـHimaya.
