# Himaya Security 0.5.0 — Development

## نطاق الإصدار

هذا الفرع مخصص لتطبيق Windows 11 x64 لإدارة حظر التطبيقات والمواقع والمجلدات محليًا. تم استبعاد موافقة الشخص الموثوق ومهلة فك الحظر 72 ساعة من نطاق المشروع بناءً على طلب المستخدم.

## الوظائف الموجودة

- واجهة Windows عربية لإدارة قوائم التطبيقات والمواقع والمجلدات.
- قاعدة بيانات SQLite محلية في `%ProgramData%\\Himaya`.
- صلاحيات مجلد بيانات البرنامج مقصورة على Administrators وSYSTEM أثناء التثبيت؛ لا يمنح المثبت حسابات المستخدمين العاديين صلاحية تعديل قاعدة البيانات.
- خدمة Windows باسم `HimayaGuard` تعمل بحساب LocalSystem وتزامن سياسات منع تشغيل التطبيقات والمجلدات.
- منع تشغيل ملفات EXE المختارة عبر Windows Software Restriction Policies (SRP).
- منع الوصول إلى المجلدات المختارة عبر ACL، مع حفظ ACL الأصلي في HKLM ومحاولة استعادته عند إزالة القاعدة أو إيقاف الخدمة.
- مدد قفل التطبيقات المؤقتة: ساعة، 24 ساعة، 7 أيام، 30 يومًا، و90 يومًا؛ القفل طويل الأجل لا ينتهي تلقائيًا.
- حظر النطاقات من قائمة مجتمعية للمحتوى الإباحي بالإضافة إلى النطاقات التي يضيفها المستخدم. يتم تنزيل القائمة عند الضغط على تطبيق حظر المواقع، وليس في الخلفية وفق جدول تلقائي.
- الحفاظ على السطور غير التابعة لـHimaya في ملف hosts عند تطبيق القواعد أو استعادتها.
- تصدير آخر 5000 حدث من سجل الحماية إلى ملف CSV بترميز UTF-8، ويمكن فتحه ببرامج الجداول.
- سجل للأحداث الأساسية مثل إضافة/حذف القواعد وتغيير وضع الملف الشخصي وتطبيق/استعادة حظر المواقع وتصدير التقارير.

## توضيحات وحدود مهمة

- خيارات «بسيط/متوسط/حاد/تعافٍ مكثف» تحفظ اختيار ملف شخصي في الإعدادات حاليًا؛ لا تطبق بعد جداول أو سياسات مختلفة تلقائيًا. لا تعتبرها أوضاع تعافٍ مكتملة.
- حظر المواقع عبر ملف hosts وليس Network Filter؛ قد تتجاوزه VPN أو Proxy أو DNS المشفر أو تطبيق يستخدم DNS خاصًا به.
- قائمة المواقع تعتمد على مصدر مجتمعي خارجي، وقد تتغير أو يتعذر تنزيلها عند انقطاع الإنترنت. لا يضمن البرنامج حجب كل المواقع.
- حظر التطبيقات والمجلدات يعتمد SRP وACL في Windows. لا توجد حماية مطلقة ضد مسؤول محلي يستطيع تغيير سياسات النظام أو إيقاف الخدمة أو إزالة البرنامج.
- إيقاف خدمة HimayaGuard يستعيد قواعد ACL المسجلة ويزيل قواعد SRP التي يديرها البرنامج؛ لذلك يؤدي إيقافها إلى تعطيل هذه الحماية عمدًا.
- عند نقل مجلد محظور أو تغيير اسمه قبل إزالة قاعدته، قد لا يتمكن البرنامج من العثور عليه لاستعادة ACL المحفوظ؛ أزل القاعدة قبل نقل المجلد أو إعادة تسميته.
- التصدير يضم آخر 5000 حدث فقط، ولا يمثل نظام تقارير تحليليًا أو لوحة إحصاءات متكاملة.
- موافقة الشخص الموثوق ومهلة فك الحظر 72 ساعة غير موجودتين في نطاق الإصدار.
- GitHub Actions يبني التطبيق والخدمة والمثبت ويشغل اختبارات آلية على Windows runner. هذا لا يغني عن اختبار التثبيت والترقية والإزالة والاستخدام على جهاز Windows 11 Pro فعلي.
