# Himaya Security – بداية المشروع

هذه أول نسخة تأسيسية من Himaya تستهدف Windows 11 Pro x64. تحتوي على واجهة عربية بسيطة لإدارة ثلاث قوائم محلية: التطبيقات والمواقع والمسارات. **إضافة عنصر لا تطبق الحظر بعد**؛ لا توجد في هذه النسخة آلية اعتراض أو منع تشغيل/وصول، ولا خدمة Windows خلفية. هذا مقصود حتى لا نغيّر إعدادات الجهاز قبل تنفيذ محرك الحماية واختباره واستعادة الإعدادات بأمان.

## كيف تحصل على ملف التثبيت من GitHub

1. أنشئ مستودع GitHub جديدًا باسم `Himaya`.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، مع تضمين مجلد `.github`.
3. افتح تبويب **Actions** في المستودع.
4. شغّل workflow باسم **Build Himaya for Windows** أو ادفع commit جديدًا إلى `main`.
5. بعد نجاح التشغيل، افتح صفحة التشغيل الناجح وانزل إلى **Artifacts**.
6. نزّل `Himaya-Windows-x64`. سيحتوي على `Himaya.exe` و`Himaya-Setup.exe`.

## البناء محليًا (اختياري)

من Developer PowerShell مع CMake وMSVC:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```
